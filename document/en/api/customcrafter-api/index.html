CustomCrafterAPI Object

What is CustomCrafterAPI

Section titled “What is CustomCrafterAPI”

CustomCrafterAPI is a Kotlin object that centrally manages retrieval, modification, and reset of CustomCrafterAPI configuration values, as well as recipe registration and deregistration. It is used for initial setup in a plugin’s onEnable, and for dynamically adding or removing recipes at runtime.

Version compatibility check

Section titled “Version compatibility check”

hasFullCompatibility(version: String) is deprecated as of 5.2.0 and will be removed in 6.0.0. Use MAJOR_VERSION, MINOR_VERSION, PATCH_VERSION, and VERSION_TYPE for version checks instead.

Recipe Management

Section titled “Recipe Management”

Retrieving recipes

Section titled “Retrieving recipes”

getRecipes() returns all registered recipes as an immutable list. Modifying the returned list does not affect recipe registration or deregistration.

getRegisteredRecipeNames() returns a set of all registered recipe names.

getRegisteredRecipeFromName(filter) returns recipes whose names satisfy the given predicate. getRegisteredRecipeFromName(recipeName) returns recipes with a name exactly matching recipeName.

getRegisteredRecipeFromPlugin(plugin) returns all recipes registered by the specified plugin instance.

Registering recipes

Section titled “Registering recipes”

Use registerRecipe(recipes: List<CRecipe>, plugin: JavaPlugin) to register recipes.

  • Validation via CRecipe.isValidRecipe() is performed at registration time; an IllegalStateException is thrown if validation fails.
  • If the current RecipeNameStrictLevel detects a duplicate name, an IllegalArgumentException is thrown.
  • After a successful registration, RegisterCustomRecipeEvent is fired.

Deregistering recipes

Section titled “Deregistering recipes”

Use unregisterRecipe(name: String?, plugin: JavaPlugin?) to deregister recipes matching the given conditions. unregisterAllRecipes() deregisters all recipes at once. Both fire an UnregisterCustomRecipeEvent.

Argument Default Behavior when null
name — Name is not used as a filter
plugin CustomCrafter.getInstance() Plugin is not used as a filter. When both are null, all recipes are deregistered

BaseBlock

Section titled “BaseBlock”

The type of block that, when placed directly beneath a crafting table, triggers the dedicated UI to open. Default: Material.GOLD_BLOCK (DEFAULT_BASE_BLOCK). If a non-block Material is specified, an IllegalArgumentException is thrown.

BaseBlockSide

Section titled “BaseBlockSide”

The side length of the block arrangement required directly beneath the crafting table. Default: 3 (3×3) (DEFAULT_BASE_BLOCK_SIDE). Only odd numbers of 3 or greater are valid; any other value causes the method to return false.

ResultGiveCancel

Section titled “ResultGiveCancel”

When set to true, CustomCrafterAPI will not deliver the crafted item to the player — instead, that responsibility is delegated to the calling plugin. Use this when you want to implement your own result-delivery logic. Default: false (DEFAULT_RESULT_GIVE_CANCEL).

UseCustomCraftUI

Section titled “UseCustomCraftUI”

When true (the default), clicking a crafting table opens the CustomCrafterAPI dedicated UI. When set to false, clicking a crafting table will no longer open the dedicated UI. Default: true (DEFAULT_USE_CUSTOM_CRAFT_UI).

UseMultipleResultCandidateFeature

Section titled “UseMultipleResultCandidateFeature”

Enables a mode that displays all matching recipe candidates to the player when multiple recipes match the input items. When false (the default), only the first recipe found is used. Default: false (DEFAULT_USE_MULTIPLE_RESULT_CANDIDATE_FEATURE).

RecipeNameStrictLevel

Section titled “RecipeNameStrictLevel”

Controls how strictly duplicate recipe names are checked during registration. The level can only be changed in the stricter direction; loosening is not permitted. Default: NameStrictLevel.NOTHING (DEFAULT_RECIPE_NAME_STRICT_LEVEL).

Level Behavior
NOTHING No duplicate check
WEAK Rejects a recipe if its name exactly matches an already-registered name
STRICT Rejects a recipe if its name, with whitespace removed, matches an already-registered name

CraftUIDesigner

Section titled “CraftUIDesigner”

Sets the designer that customizes the appearance of the crafting UI. See the CraftUIDesigner page for details. Default: CraftUIDesigner.DEFAULT (DEFAULT_CRAFT_UI_DESIGNER).

AllCandidateUIDesigner

Section titled “AllCandidateUIDesigner”

Sets the designer that customizes the appearance of the AllCandidateUI. See the AllCandidateUIDesigner page for details. Default: AllCandidateUIDesigner.DEFAULT (DEFAULT_ALL_CANDIDATE_UI_DESIGNER).
